Food Delivery Service Data Cleaning

Project Overview

This project focuses on cleaning and analyzing a food delivery dataset using Microsoft Excel. It improves data quality by handling missing values, correcting errors, standardizing formats, and removing duplicate-looking records.

Objectives

- Identify and handle missing and invalid data.
- Standardize city names, order statuses, and dates.
- Correct quantity and price errors.
- Calculate total order amounts.
- Analyze orders by food item and city.

Tools Used

- Microsoft Excel
- Excel formulas

 Project Files

- "Messy_Data.xlsx" – Original dataset
- "Cleaned_Data.xlsx" – Cleaned dataset
- "Food_Delivery_Data_Cleaning_Report.pdf" – Project report

 Key Results

- Cleaned records: 13
- Total order value: ₹5,440
- Average order value: ₹418.46
- Highest-value food item: Pizza

Conclusion

This project demonstrates how data cleaning improves data consistency and supports meaningful analysis of food delivery orders.
